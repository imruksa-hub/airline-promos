# รวมโปรสายการบิน

เว็บรวมโปรโมชั่นตั๋วเครื่องบินและกิจกรรมชิงโชคของหลายสายการบินไว้ในหน้าเดียว
อัปเดตอัตโนมัติทุก 4 ชั่วโมงด้วย GitHub Actions และเปิดเว็บด้วย GitHub Pages (ฟรี)

เว็บนี้ **แสดงรายการและลิงก์** ไปยังหน้าโปรหรือหน้าร่วมสนุกเท่านั้น ไม่ได้ส่งชื่อเข้าร่วมชิงโชคแทนผู้ใช้
เพราะกติกาชิงโชคส่วนใหญ่ห้ามการร่วมแบบอัตโนมัติ

## ส่วนประกอบ

| ไฟล์ | หน้าที่ |
|---|---|
| `sources.json` | รายชื่อสายการบินและหน้าโปรโมชั่นที่จะดึง |
| `manual.json` | รายการที่เพิ่มเอง เช่น โพสต์ชิงโชคจาก Facebook / IG |
| `scraper/collect.py` | สคริปต์ดึงข้อมูล (Python ล้วน ไม่ต้องติดตั้งแพ็กเกจ) เคารพ robots.txt |
| `site/` | หน้าเว็บ (HTML/CSS/JS) อ่านข้อมูลจาก `site/data/promos.json` |
| `.github/workflows/update.yml` | รันทุก 4 ชั่วโมง: ทดสอบ → ดึงข้อมูล → บันทึก → deploy |

## เปิดใช้ครั้งแรก

1. Push โค้ดนี้ขึ้น GitHub
2. ไปที่ **Settings → Pages** แล้วเลือก Source เป็น **GitHub Actions**
3. ไปที่แท็บ **Actions** → เลือก *Update promotions and deploy* → **Run workflow**
4. รอ 1–3 นาที เว็บจะอยู่ที่ `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/`

ดูหน้าตาด้วยข้อมูลตัวอย่างได้ที่ `.../?demo=1`

## เพิ่มรายการเอง (`manual.json`)

```json
[
  {
    "airline": "nokair",
    "type": "draw",
    "title": "ลุ้นชิงตั๋วฟรี 2 ที่นั่ง",
    "url": "https://www.facebook.com/...",
    "deadline": "2026-12-15",
    "description": "คอมเมนต์ใต้โพสต์ตามกติกา"
  }
]
```

`type` เป็น `fare` (โปรตั๋ว) หรือ `draw` (ชิงโชค) และ `airline` ใช้ `id` จาก `sources.json`
รายการที่เลยวันหมดเขตจะถูกซ่อนอัตโนมัติ

## เพิ่มสายการบิน

เพิ่มบรรทัดใน `sources.json` โดยใส่ `id`, `name`, `name_th` และ `url` ของหน้าโปรโมชั่น

## ทดสอบบนเครื่อง

```bash
python -m unittest discover -s tests
python scraper/collect.py
cd site && python -m http.server 8000   # เปิด http://localhost:8000
```

## ข้อจำกัดที่รู้อยู่

- บางสายการบินสร้างหน้าโปรด้วย JavaScript หรือบล็อกบอท หน้าเหล่านี้อาจดึงไม่ได้ ดูสถานะได้ที่ท้ายหน้าเว็บ
  ถ้าจำเป็นค่อยเพิ่มเบราว์เซอร์อัตโนมัติ (Playwright) หรือใช้ `manual.json`
- วันหมดเขตเดาจากข้อความในหน้า (รองรับวันที่ไทยและอังกฤษ) ควรตรวจกับหน้าจริงอีกครั้ง
- Facebook / Instagram ห้ามดึงอัตโนมัติ จึงใช้ `manual.json` แทน
